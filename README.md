## Data Cleaning Done in Excel App
- Fixed encoded column ï»¿Age -> Age
- Removed constant columns: Over18, EmployeeCount, StandardHours (all same value)

- Used Filter to analyze attrition: Yes = 237 employees

## Key Insights from Dashboard
- Overall Attrition: 16.1% (237 out of 1470 left)
- Overtime Impact: Overtime Yes = 30.5% attrition (127/416) vs Overtime No = 10.4% (110/1054) - 3x higher risk!
- Department: Sales highest attrition
- Job Role: Sales Executive, Lab Technician high attrition
- Age: Younger employees (25-35) leaving more
- Recommendation: Reduce overtime, improve work-life balance, focus on Sales dept retention, increase salary hike for young talent
